# 💎 Duha’s Jewellery

A modern and responsive **jewelry e-commerce platform** designed to provide a smooth and elegant online shopping experience. The platform allows customers to explore jewelry collections, configure products, manage their cart, apply promotional offers, and place orders through WhatsApp.

## 🌐 Live Demo

**[Visit Duha’s Jewellery](https://duhas-jewellery.vercel.app/)**

## ✨ Features

* 🛍️ Modern and responsive e-commerce interface
* 💎 Jewelry product catalog and collections
* 🛒 Dynamic shopping cart
* 📏 Interactive ring size guide
* 🎟️ Promo codes and discounts
* ⭐ Loyalty points system
* 📱 WhatsApp order integration
* 💳 Multiple payment options
* 🔐 Supabase backend integration
* 📱 Mobile-friendly design
* ⚡ Fast deployment with Vercel

## 🛠️ Tech Stack

* **HTML5** — Website structure
* **CSS3** — Responsive design and styling
* **JavaScript** — Interactive functionality and business logic
* **Supabase** — Database and backend services
* **Vercel** — Deployment and hosting

## 🎯 Project Goal

The goal of this project was to build a complete and user-friendly online jewelry store that combines an elegant shopping experience with practical e-commerce functionality.

## 🚀 Deployment
